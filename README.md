# CPU Physics Olympiad classroom

The Astro and React classroom runs on Cloudflare Workers. It supports student registration, administrator-managed accounts, and interactive problem sets with separate release controls for questions and solutions.

The application source and generic package authoring guide are included here. Teachers upload course packages through the classroom. Student records and uploaded teaching materials live in the classroom database.

See the [setup and administration guide](web/README.md) to run the site locally. The [package authoring guide](web/public/course-package-guide.md) describes the upload format.
